# Product pitch (100 words)

Smart Market Watch answers one question: what changed since I last looked, and does it matter? Each user's last-seen price per symbol is stored server-side, so every return visit compares against what they actually saw, not yesterday's close. Moves are scored against each stock's own volatility and volume, so a 2% move in a quiet name outranks 2% in a volatile one, and every alert carries a plain-English "why" with evidence. Quotes are labelled LIVE, DELAYED, STALE or UNAVAILABLE, and a provider outage never overwrites good data. Snapshots are shared across users, so cost scales with distinct symbols, not users.
